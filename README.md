## 👤 About

I like the parts of software where breaking something on purpose teaches you more than the documentation does. That's what pulled me from application development into CI/CD and security tooling: pipelines fail in interesting ways, and SIEM dashboards only get better once you've watched a real detection rule miss something.

Right now I'm a working student at a security consultancy, running GitLab pipelines across roughly 50–70 pull requests a day and building out dashboards in Google SecOps (Chronicle). Before that I spent three years as a software development apprentice, writing EDI interfaces in Java and helping build an internal server monitoring setup from scratch. I also hold Google's Cybersecurity Professional Certificate, covering SIEM tooling, IDS, and the NIST Cybersecurity Framework.

## 🚀 Projects

**Tessera** is an entry-monitoring and access-control system I'm building: QR-code admission cards, a mobile scanner, role-based permissions (Owner, Event Admin, Scanner), dual authentication, and duplicate-scan protection. It runs in production behind systemd and Caddy as a TLS reverse proxy.

I've also merged 18 pull requests across open-source repositories, including 6 in NixOS/nixpkgs, where I maintain the `stoat-desktop` package, plus a handful of additions to *european-alternatives*.

At home I run a self-hosted Wazuh SIEM across my network — log aggregation, file integrity monitoring, intrusion detection, and a growing set of custom detection rules and dashboards.
